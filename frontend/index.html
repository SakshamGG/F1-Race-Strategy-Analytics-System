Database Features Demonstration

Advanced DBMS features implemented in this project:

✅ CRUD Operations

Full Create, Read, Update, Delete on all 12 entities (Drivers, Constructors, Circuits, Races, etc.)

✅ Foreign Keys

18 foreign key constraints enforce referential integrity across all related tables.

✅ JOIN Queries

Multi-table JOINs for race results, standings, and telemetry with human-readable output.

✅ Database Views

5 views: v_race_results_detailed, v_lap_times_detailed, v_pit_stops_detailed, v_driver_standings, v_constructor_standings

✅ Triggers

7 triggers: lap/pit validation, F1 tyre rule enforcement, and full audit trail on strategy notes.

✅ Stored Procedures

sp_recalculate_standings, sp_simulate_strategy, sp_validate_race_tyre_rules

✅ External API Integration

Jolpica F1 API (drivers, constructors, circuits, races, results, laps, pit stops) and OpenF1 API (weather, telemetry).
